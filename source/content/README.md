# 网站文案与配图｜案例版

本文件夹包含 6 篇[产品解决方案](产品解决方案_案例版.md)、4 篇真实公开案例写成的[行业观察及 2 篇活动预告模板](新闻与活动_案例版.md)，以及 13 张已归档的配图和[来源／使用清单](配图清单.md)。

产品参数来自用户提供的三本画册。公开案例来自 USGS、美国能源部、Verizon 和 NASA 的原始资料。案例旨在说明行业需求与可参考的工作流程，**不代表这些机构使用、采购或认可画册产品**。活动内容是拟发布模板，不是已举办活动。

发布时建议保留各案例的原文链接、图片来源和“行业案例配图”说明。USGS 图片页面标注 Public Domain；画册图片由用户提供，若网站面向公众发布，请由素材权利方确认使用范围。少数画册图片分辨率较低，适合小图或辅助图，不宜放大全屏。
